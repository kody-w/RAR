# RAPP Scout starter

Import this directory in Microsoft Scout to install the Toasted `rapp-skills` manager, Brainstem bridge, and the RAPP/1 `rapp-agent-converter`. Toasted `SKILL.md` is the persistent Grail record; `agent.py` is generated only when selected or hotloaded. Use `scripts/toast.py config --default-format agent` to flip the global materialization without changing the canonical record.
