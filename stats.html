Public, aggregate figures for the RAPP Agent Registry — what the catalog holds, how far it reaches, and how it is received.

Catalog

What exists. Counted directly from registry.json, which is rebuilt from the agent files on every push.

Reach

How far agents travel. Release downloads are counted by GitHub itself, server-side, and include people who were never signed in. Acquisitions are counted per person, so repeat installs by the same person count once.

Reception

One tap on an agent’s thread, no form. Each row is a separate counter and each person can appear in more than one, so rows do not sum to a total — they are seven independent questions, each answered by a number of people.

Aggregated libraries

Other public agent and skill libraries indexed here. Metadata and links only — content is never copied, so each entry points back to its origin. Where a library publishes its own engagement numbers those are shown as reported, kept separate from this registry’s own counters: they count different populations by different methods, so adding them together would produce a figure neither system could defend.

Instrumentation coverage

Whether the measurement exists at all, kept deliberately separate from what it has measured so far. A count of zero against full coverage means “asked, not yet answered” — not “broken”.

Composition

How the catalog is distributed across review tiers and problem areas.

What this does not measure

  • Anything about a person. No names, no accounts, no per-person history. Every figure here is a count of distinct people or of catalog objects — never who they were.
  • Anything you typed. Prompts, chat, agent inputs and outputs are never recorded anywhere in this system.
  • Page visits. The site is static with no analytics of any kind, so there is no visitor count and cannot be one.
  • What happens after download. Whether an agent was run, changed, or deployed is not observable from here.
  • Downloads by direct file URL. Source files stay openly fetchable, and those fetches are uncounted — every reach figure is a floor, not a total.
