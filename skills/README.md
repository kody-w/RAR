# RAR Skills metadata

RAR keeps portable skills separate from executable `agents/**/*.py` entries.
Each accepted skill has one reviewed catalog record at:

```text
skills/@publisher/skill-slug/manifest.json
```

The record points to a full immutable Git commit and lists every source file
with its SHA-256. Source files remain in their authoritative repository; RAR
does not execute them while building the catalog.

Do not add live records here by hand. Submit `rar-skill/1.0` metadata through
the versioned GitHub Issue front door documented in `CONTRIBUTING.md` and
`skill.md`. `api/v1/skills.json` is generated by
`scripts/build_skills_catalog.py`.
