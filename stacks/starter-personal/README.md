# Personal starter

For your own life: everything new on the grail, a Brainstem that looks after its computer, private topics that stay home, money watch, paperwork and moving day.

A starter pack only lists other packs; they all install into your ONE Brainstem as layers and agents, all or nothing:

- grail-layers
- money-watch
- moving-day
- night-watch
- paperwork-desk
- private-mode
- ticket-page

Version 1.2.1 removes the retired inheritance pack, which contained no succession code.

```bash
curl -fsSL https://kody-w.github.io/grail-layers/add.sh | bash -s -- starter-personal
```
