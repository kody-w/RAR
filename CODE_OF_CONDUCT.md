# Code of Conduct

RAR has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
for project spaces, issues, pull requests, discussions, and community events.

Helpful resources:

- [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)
- [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
- [GitHub abuse and content reporting](https://support.github.com/contact/report-abuse)

RAR is an independent community project, not a Microsoft-maintained
repository. Do not send RAR reports to Microsoft employee-only moderation
channels. For a private repository concern, contact the repository maintainers
through GitHub's private security-advisory flow.

Project maintainers may remove, edit, or reject contributions and participation
that violate this policy.
