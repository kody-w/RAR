# Inheritance

Say "if something happens to me, Jane gets this". The Grail layers chat agent mints Jane's key, records her public key in your Brainstem's own chain, and tells you where her key file is so you can hand it to her in person. After 30 days of silence plus 7 to confirm, she can take over, signed. Say "who gets this if something happens to me" any time. This pack includes Grail layers, which carries it.
