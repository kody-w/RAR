# Business starter

For a small business: the grail with every model, Night Watch, Private Mode for client matters, a Microsoft 365 agent team, Claude workflows and a regression judge for your agents.

A starter pack only lists other packs; they all install into your ONE Brainstem as layers and agents, all or nothing:

- grail-layers
- night-watch
- private-mode
- microsoft-365-team
- claude-workflows
- judge

```bash
curl -fsSL https://kody-w.github.io/grail-layers/add.sh | bash -s -- starter-business
```
