# RAPP Crispy

Native macOS 14+ meeting app with graphical record/stop/cancel, app-owned microphone permissions, explicitly named Apple AVFoundation voice processing, bundled local Whisper transcription, meeting history and audio/transcript views. Optional screen/window capture is video only. Notes stay disabled until a provider is selected, approved and requested. Existing Python/CLI integration remains secondary; DeepFilterNet, RNNoise and compatible loopback routing are optional unbundled legacy paths, not the native default.

Moved here from the RAPP Store (now an alias of RAR); the original page keeps working: https://kody-w.github.io/RAPP_Store/#rapp_crispy
