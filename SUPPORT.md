# Support

RAR is a community open-source project. It is not covered by Microsoft
Customer Service and Support.

## Bugs and Feature Requests

Search existing issues before filing a new one:

- [Report a bug](https://github.com/kody-w/RAR/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/kody-w/RAR/issues/new?template=feature_request.yml)

Use the canonical agent mutation path in [CONTRIBUTING.md](CONTRIBUTING.md) for
agent publication, update, restore, or deletion. Do not submit canonical agent
bytes through a normal pull request.

## Questions

Use [GitHub Discussions](https://github.com/kody-w/RAR/discussions) for usage,
architecture, Scout/Copilot installation, and integration questions.

## Security

Security vulnerabilities must use the private process in
[SECURITY.md](SECURITY.md), never a public support thread.
